;Program 14: : Checks if the number is even or odd and prints E (even) or 0 (odd)

2000 ; R0 = 00 (for comparison)
210B ; R1 = 11
2201 ; R2 = 01
8312 ; R3 = R1 AND R2
B310 ; Jump If R3 = R0 (even), jump to address 10
244F ; Load 4F ('0') into R4
34FF ; Display R4
CO00 ; Halt
2445 ; (address 10) Load 45 ('E') into R4
34FF ; Display R4 (screen output)
CO00 ; Halt
